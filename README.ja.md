<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/Assets/Images/helisphere.png" width="35"/> Heli Sphere</h1>

<p align="center">
  Heli Sphereでは、AR（拡張現実）を使用して、現実の環境内で3Dヘリコプターを自由に飛行させることができます。
</p>

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/features.gif" width="35"/> 機能

| 機能 | 説明 |
| --- | --- |
| 🚁 **複数のヘリコプター** | さまざまな3Dヘリコプターモデルから選択できます |
| 🔧 **サイズ調整** | AR環境に合わせてヘリコプターのサイズを変更できます |
| 🎚️ **速度調整** | 飛行中のヘリコプターの速度をリアルタイムで調整できます |
| 🗺️ **位置と移動** | 現実の空間内でヘリコプターを自由に移動・配置できます |
| 📸 **撮影機能** | AR環境内のヘリコプターを写真として撮影できます |
| 🕹️ **ジョイスティック操作** | 直感的なジョイスティックでヘリコプターを操縦できます |
| 🎙️ **パイロット音声コマンド** | 飛行中のリアルなパイロット通信を聞くことができます |

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/heli-sphere.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd heli-sphere
```

### 3️⃣ Unity Hubに追加

- **Unity Hub**を開き、**Add**を選択して、クローンした**heli-sphere**フォルダを指定します。

### 4️⃣ プロジェクトを開く

- Unityによるプロジェクトファイルのインポートが完了したら、**Assets**フォルダからメインシーンを開きます。

### 5️⃣ プロジェクトを実行

- Unity Editorの**Play**ボタンを押して、Heli Sphereを起動します。

<img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/howItWorks.gif" width="35"/> 使い方

1️⃣ **Heli Sphere**を起動し、AR機能を使用するためにカメラへのアクセスを許可します。

2️⃣ カメラを周囲の環境に向けます。

3️⃣ ヘリコプターを選択し、現実の環境内で自由に飛行させます。

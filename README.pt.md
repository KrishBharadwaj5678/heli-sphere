<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/Assets/Images/helisphere.png" width="35"/> Heli Sphere</h1>

<p align="center">
  O Heli Sphere permite que você pilote um helicóptero 3D no seu próprio ambiente usando Realidade Aumentada (AR).
</p>

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| --- | --- |
| 🚁 **Vários Helicópteros** | Escolha entre diversos modelos de helicópteros 3D |
| 🔧 **Escala Ajustável** | Redimensione o helicóptero para se adaptar ao seu ambiente de AR |
| 🎚️ **Controle de Velocidade** | Ajuste a velocidade de voo do helicóptero em tempo real |
| 🗺️ **Posição e Movimento** | Mova e posicione o helicóptero livremente ao seu redor |
| 📸 **Captura de Fotos** | Tire fotos do helicóptero dentro do ambiente de AR |
| 🕹️ **Controle por Joystick** | Pilote e manobre o helicóptero usando controles intuitivos de joystick |
| 🎙️ **Comandos de Voz do Piloto** | Ouça comunicações realistas do piloto durante o voo |

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Primeiros Passos

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/heli-sphere.git
```

### 2️⃣ Acesse a Pasta do Projeto

```bash
cd heli-sphere
```

### 3️⃣ Adicione ao Unity Hub

- Abra o **Unity Hub**, selecione **Add** e escolha a pasta **heli-sphere** que foi clonada.

### 4️⃣ Abra o Projeto

- Depois que o Unity terminar de importar os arquivos do projeto, abra a cena principal dentro da pasta **Assets**.

### 5️⃣ Execute o Projeto

- Pressione o botão **Play** no Unity Editor para iniciar o Heli Sphere.

<img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/howItWorks.gif" width="35"/> Como Funciona

1️⃣ Abra o **Heli Sphere** e conceda permissão para acessar a câmera para utilizar os recursos de Realidade Aumentada.

2️⃣ Aponte a câmera para o ambiente ao seu redor.

3️⃣ Escolha um helicóptero e pilote-o livremente pelo seu ambiente.

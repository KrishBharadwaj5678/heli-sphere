## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/features.gif" width="35"/> Возможности

| Возможность | Описание |
| --- | --- |
| 🚁 **Несколько вертолётов** | Выбирайте из различных 3D-моделей вертолётов |
| 🔧 **Настраиваемый масштаб** | Изменяйте размер вертолёта в соответствии с вашим AR-окружением |
| 🎚️ **Управление скоростью** | Регулируйте скорость полёта вертолёта в реальном времени |
| 🗺️ **Позиционирование и движение** | Свободно перемещайте и позиционируйте вертолёт в пространстве |
| 📸 **Фотосъёмка** | Делайте фотографии вертолёта внутри AR-окружения |
| 🕹️ **Управление джойстиком** | Пилотируйте вертолёт с помощью удобного виртуального джойстика |
| 🎙️ **Голосовые команды пилота** | Слушайте реалистичные переговоры пилота во время полёта |

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/heli-sphere.git
```

### 2️⃣ Переход в папку проекта

```bash
cd heli-sphere
```

### 3️⃣ Добавление проекта в Unity Hub

- Откройте **Unity Hub**, выберите **Add** и укажите склонированную папку **heli-sphere**

### 4️⃣ Открытие проекта

- После завершения импорта файлов Unity откройте основную сцену из папки **Assets**

### 5️⃣ Запуск проекта

- Нажмите кнопку **Play** в Unity Editor, чтобы запустить Heli Sphere

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/howItWorks.gif" width="35"/> Как это работает

1️⃣ Откройте Heli Sphere и разрешите доступ к камере для AR.

2️⃣ Наведите камеру на окружающее пространство.

3️⃣ Выберите вертолёт и свободно управляйте им в реальном окружении.

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/heli-sphere.git
```

### 2️⃣ Navigate to the Project

```bash
cd heli-sphere
```

### 3️⃣ Add to Unity Hub

- Open **Unity Hub**, select **Add**, and choose the cloned **heli-sphere** folder

### 4️⃣ Open the Project

- Once Unity finishes importing the project files, open the main scene from the **Assets** folder

### 5️⃣ Run the Project

- Press the **Play** button in Unity Editor to launch Heli Sphere

## <img src="https://github.com/KrishBharadwaj5678/heli-sphere/raw/main/readme/gifs/howItWorks.gif" width="35"/> How It Works 

1️⃣ Open **Heli Sphere** and grant camera permissions for AR functionality.

2️⃣ Point your camera at your surroundings.

3️⃣ Choose a helicopter and fly it freely around your environment.
